# 利用用途アンケート v1

背景透過・背景合成の待ち時間に任意の1問を表示する。未回答なら結果画面へ引き継ぎ、ダウンロードは回答に関係なく使える。ZIP準備・高画質化のみの実行では新規表示しない。全件失敗・キャンセルで閉じる。

ブラウザの `quicktools:usage-survey:v1` に回答済みフラグと最終表示日時を保存する。表示から7日間は新規表示せず、回答後は同じ版を表示しない。別端末や保存情報削除後は重複し得る。保存不能時はページ内の状態で抑制する。

## イベント

| イベント | タイミング |
| --- | --- |
| `usage_survey_view` | 質問の初回表示。結果画面への引き継ぎでは再送しない |
| `usage_survey_answer` | 選択肢を押したとき。一度だけ送信 |
| `usage_survey_dismiss` | 「回答しない」を押したとき。処理終了・失敗による非表示では送らない |

共通パラメータは `survey_version`（v1）、`placement`（processing/result）、`user_plan`（guest/free/pro）、`processing_mode`（standard/pro_high_precision/ai_generate）、`image_count`（今回の処理対象枚数）。処理モード・プラン・枚数は処理開始時点の値を保持する。回答だけに `purpose` を付ける。

| purpose | 用途 |
| --- | --- |
| work_presentation | 仕事の資料・プレゼン |
| design_marketing | Web・広告・チラシなどの制作 |
| ecommerce | 商品出品・ネットショップ |
| personal | 個人のSNS・趣味 |
| other | その他 |

画像、ファイル名、メールアドレスはアンケートのパラメータに含めない。DBへの保存はない。GA4未読込・広告ブロックなどでは回答が計測されない場合があり、再送しない。画面の完了表示はGA4への到達保証ではない。

## 公開時のGA4設定（管理画面で別途実施）

1. 対象サイトのGA4プロパティを開き、管理 → カスタム定義 → カスタムディメンションを作成する。編集者以上の権限が必要。
2. 範囲を「イベント」にし、`survey_version`、`placement`、`user_plan`、`processing_mode`、`purpose` をそれぞれイベントパラメータとして登録する。同名の既存定義があれば再利用する。
3. 枚数を集計する場合はカスタム指標に `image_count` を登録し、測定単位は標準とする。合計枚数を見る際はイベント名で絞り、閲覧と回答の枚数を二重に足さない。
4. DebugViewでテストブラウザの3イベントと値を確認する。確認用に当該ブラウザの上記localStorageキーだけ削除すれば再表示できる。本番利用者のデータは変更しない。
5. 探索でイベント数を確認し、回答イベントに絞って用途別・利用プラン別・処理モード別に集計する。登録した定義がレポートに反映されるまで24〜48時間程度かかる場合がある。

設定手順の根拠：[Google公式・イベントスコープのカスタムディメンション](https://support.google.com/analytics/answer/14239696?hl=ja)、[カスタム指標](https://support.google.com/analytics/answer/14239619?hl=ja)、[カスタム定義について](https://support.google.com/analytics/answer/14240153?hl=ja)。コード変更だけではGA4管理画面の定義は作成されない。

## 評価と確認

- 回答率は同期間・同じ版の回答イベント数 ÷ 閲覧イベント数。日をまたぐ回答や計測欠損により厳密なコホート回答率ではない。
- 用途の割合は「回答者の用途」。任意回答、処理の長さ、ブラウザ単位の再表示制御による偏りがあり、全利用者の割合と同一視しない。
- モバイルで進捗・質問・キャンセルへスクロールできること、Tab操作がモーダル内で循環すること、処理終了後にフォーカスが戻ることを確認する。
- 単体保存・ZIP保存、回答・スキップ・無回答、部分成功・全件失敗・キャンセルを確認する。7日境界・保存情報破損・保存不能・GA4未読込は自動テスト対象。
